# t66y-blacklist

`t66y-blacklist` 是一个功能强大的 t66y 论坛用户脚本，支持按用户名、UID、关键词屏蔽内容，提供黑名单管理、悬浮卡片快捷拉黑等功能。

## ✨ 功能特性

### 核心功能
- **用户屏蔽**：按用户名或 UID 屏蔽用户的所有内容
- **关键词屏蔽**：按关键词屏蔽回帖内容（不区分大小写，支持正则优化）
- **楼主保护**：楼主发言不会因关键词被屏蔽（除非楼主本身在黑名单）
- **显隐切换**：在帖子页快速切换"显示/隐藏已屏蔽"内容

### 悬浮卡片
- 鼠标悬停用户名时显示悬浮卡片
- 查看用户最近发帖历史摘要（带缓存）
- 一键拉黑/取消拉黑
- 智能排除分页链接、功能按钮（今日主題、精華主題等）

### 黑名单管理
- 用户名/UID/关键词分组管理
- 分页浏览（每页 10 条）
- 实时搜索过滤
- 导入/导出 JSON 备份
- 清空黑名单（带确认对话框）

### 性能优化
- 关键词匹配使用正则表达式，O(1) 复杂度
- 悬浮卡片尺寸缓存，减少回流
- 定时清理已移除的 DOM 元素，防止内存泄漏
- Fetch 请求自动 8 秒超时

## 📦 安装方式

1. 安装用户脚本管理器（推荐 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)）
2. 新建脚本并粘贴 `t66y-blacklist.user.js` 全部内容
3. 保存后刷新目标页面

## ⚙️ 配置项

脚本内 `CONFIG` 可配置：

```javascript
const CONFIG = {
  initialBlockedUsernames: [],  // 首次运行时默认用户名黑名单
  initialBlockedUids: ['123456', '654321'],  // 首次运行时默认 UID 黑名单
  initialBlockedKeywords: [],  // 首次运行时默认关键词黑名单
  hideTopicListIfLastReplyByBlocked: false,  // 是否按"最后回复人"隐藏主题
};
```

**说明**：
- `initial*` 配置仅在首次运行且本地无存储数据时生效
- 后续以本地存储为准（`localStorage`）
- 可通过管理面板导入/导出 JSON 进行数据迁移

## 📖 使用说明

### 屏蔽规则

1. **用户屏蔽**：命中用户名或 UID 即屏蔽该用户的所有内容
2. **关键词屏蔽**：
   - 仅检查"非楼主回帖正文"
   - 自动移除工具栏、按钮等非正文内容
   - 不区分大小写

### 黑名单管理

1. 点击页面右下角"黑名单管理"按钮打开管理面板
2. 支持以下操作：
   - **添加关键词**：输入框输入后点击"添加"或按回车
   - **移除条目**：点击每条记录后的"移除"按钮
   - **搜索过滤**：输入搜索词实时过滤结果
   - **分页浏览**：每页显示 10 条记录
   - **导出备份**：点击"复制导出"复制 JSON 到剪贴板
   - **导入备份**：粘贴 JSON 后点击"覆盖导入"
   - **清空黑名单**：点击"清空黑名单"（需确认）

### 悬浮卡片

1. 鼠标悬停在用户名链接上自动显示悬浮卡片
2. 卡片内容：
   - 用户名和 UID
   - 拉黑状态
   - 最近发帖历史（最多 20 条，缓存 10 分钟）
3. 操作按钮：
   - **一键拉黑**：立即添加到黑名单
   - **取消拉黑**：从黑名单移除
   - **展开全部**：查看完整历史列表

## 💾 数据存储

- **存储键**：`__t66y_blacklist_v2__`
- **存储内容**：
  ```json
  {
    "usernames": ["用户名1", "用户名2"],
    "uids": ["123456", "654321"],
    "keywords": ["关键词1", "关键词2"],
    "exportedAt": "2024-01-01T00:00:00.000Z"
  }
  ```
- **存储位置**：浏览器 `localStorage`

## 🔧 技术亮点

- **楼主判断**：通过 DOM 结构检查 `<span class="sgreen">[樓主]</span>` 标签
- **UID 解析**：优先匹配 `uid`/`authorid`/`touid`，避免 `search` 参数混淆
- **关键词优化**：使用预编译正则表达式，避免循环匹配
- **内存管理**：定时清理已移除的 DOM 引用
- **现代 API**：优先使用 `navigator.clipboard.writeText()`，兼容降级方案
- **超时控制**：使用 `AbortController` 实现 Fetch 超时

## ⚠️ 已知限制

- 论坛页面结构若大改，可能需要更新选择器
- 若其他脚本大规模改写帖子 DOM，关键词识别可能需要针对性适配
- 悬浮卡片的历史发帖依赖于论坛搜索页的 HTML 结构
