# t66y-blacklist.js

`t66y-blacklist.js` 是一个用于 t66y 论坛的用户脚本，支持按用户名、UID、关键词屏蔽内容，并提供黑名单管理、悬浮卡片快捷拉黑、帖子页自动补页等能力。

## 功能概览

- 按用户名屏蔽用户
- 按 UID 屏蔽用户
- 按关键词屏蔽回帖内容（不区分大小写）
- 楼主保护：
  - 楼主不因关键词被屏蔽
  - 仅当楼主本身在黑名单（用户名或 UID）时才屏蔽
- 帖子页“显示/隐藏已屏蔽”切换
- 用户名悬浮卡片：
  - 一键拉黑
  - 取消拉黑
  - 查看最近发帖历史摘要（带缓存）
- 黑名单管理面板：
  - 用户名/UID/关键词分组管理
  - 分页浏览
  - 搜索过滤
  - 导入/导出 JSON 备份
- 自动补页（帖子页）：
  - 当本页存在被屏蔽回帖且滚动到底部附近时，自动加载下一页回帖追加到当前页
  - 支持连续补页与重复 URL 跳过

## 适用页面

脚本匹配以下地址：

- `*://t66y.com/thread0806.php*`
- `*://t66y.com/read.php*`
- `*://t66y.com/htm_data/*/*/*.html*`

## 安装方式

1. 安装用户脚本管理器（如 Tampermonkey 或 Violentmonkey）。
2. 新建脚本并粘贴 `t66y-blacklist.js` 全部内容。
3. 保存后刷新目标页面。

## 配置项

脚本内 `CONFIG` 可配置：

- `initialBlockedUsernames`: 首次运行时默认用户名黑名单
- `initialBlockedUids`: 首次运行时默认 UID 黑名单
- `initialBlockedKeywords`: 首次运行时默认关键词黑名单
- `hideTopicListIfLastReplyByBlocked`: 是否在主题列表中按“最后回复人”额外隐藏主题

说明：

- 这些 `initial*` 仅在首次运行且本地无存储数据时生效。
- 后续以本地存储为准（`localStorage`）。

## 使用说明

### 1. 屏蔽规则

- 用户屏蔽：命中用户名或 UID 即屏蔽该用户对应内容。
- 关键词屏蔽：仅检查“非楼主回帖正文”。

### 2. 黑名单管理

- 页面工具栏可打开管理面板。
- 支持添加/删除用户名、UID、关键词。
- 支持导出 JSON、导入 JSON、清空黑名单。

### 3. 自动补页

- 仅帖子页启用。
- 触发条件：
  - 当前页存在被屏蔽回帖
  - 滚动到页面底部附近
- 行为：
  - 预取下一页回帖并追加到当前文档
  - 追加后立即执行同一套屏蔽逻辑

## 数据存储

- 本地存储键：`__t66y_blacklist_v2__`
- 存储内容：
  - `usernames`
  - `uids`
  - `keywords`

## 已知限制

- 论坛页面结构若大改，可能需要更新选择器。
- 若其他脚本大规模改写帖子 DOM，关键词识别可能需要针对性适配。
- 自动补页依赖页面分页链接或页码参数可解析。

## 排查建议

当出现误屏蔽或补页中断时，建议提供：

1. 问题页面 URL
2. 脚本管理器与版本
3. 控制台采样信息（分页链接、楼层数量、滚动高度）
4. 误屏蔽楼层的作者信息与正文预览

## 版本与维护建议

- 每次改动建议先在“有关键词命中 + 有楼主回帖 + 多页回复”的帖子里回归测试。
- 建议维护一组最小测试场景：
  - 楼主含关键词但不应被屏蔽
  - 普通回复含关键词应被屏蔽
  - 自动补页连续翻到 3 页以上
