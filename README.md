# t66y-blacklist

一个用于 `t66y.com` 的 Tampermonkey 脚本：  
在不破坏原站阅读节奏的前提下，提供用户黑名单屏蔽、悬浮快速拉黑/取消拉黑、历史发帖预览、黑名单管理与导入导出备份能力。

## 功能特性

- 按用户名或 UID 屏蔽用户内容（主题列表与帖子页）
- 鼠标悬浮用户名显示信息卡片
- 信息卡片展示该用户历史发帖标题（默认 5 条，可展开全部）
- 一键拉黑 / 取消拉黑
- 显示已屏蔽内容开关（便于回查与撤销）
- 黑名单管理面板
  - 搜索过滤（支持用户名/UID）
  - 分页展示（每页 10 条）
  - 单项移除与清空
- 黑名单导出/复制/导入（JSON 覆盖导入）

## 运行环境

- 浏览器：Chrome / Edge / Firefox（最新版优先）
- 扩展：Tampermonkey
- 站点：`t66y.com`

## 安装方法

1. 安装 Tampermonkey 扩展。
2. 新建脚本，将 `t66y-blacklist.js` 内容粘贴保存。
3. 打开或刷新 `t66y.com` 相关页面。

## 使用说明

### 1) 悬浮卡片操作

- 鼠标移动到用户名链接上，弹出悬浮卡片
- 可执行：
  - `一键拉黑`
  - `取消拉黑`
  - `展开全部 / 收起`历史发帖标题

### 2) 页面右下角工具条

- `显示已屏蔽 / 隐藏已屏蔽`：切换被屏蔽内容可见性
- `黑名单管理`：打开管理面板

### 3) 黑名单管理面板

- 搜索框：按用户名或 UID 过滤
- 分页：用户名与 UID 各自独立分页（每页 10 条）
- 支持移除单条、清空黑名单
- 备份与恢复：
  - `刷新导出`：生成当前黑名单 JSON
  - `复制导出`：复制 JSON 到剪贴板
  - `覆盖导入`：粘贴 JSON 后覆盖现有黑名单

## 数据存储

- 本地存储键名：`__t66y_blacklist_v2__`
- 结构示例：

```json
{
  "usernames": ["example_user_a", "example_user_b"],
  "uids": ["123456", "654321"]
}
```

> 说明：用户名会在脚本内部做标准化（去空白 + 小写）后参与匹配。

## 配置项

脚本内 `CONFIG` 提供默认初始化配置：

- `initialBlockedUsernames`: 首次运行时导入的默认用户名
- `initialBlockedUids`: 首次运行时导入的默认 UID
- `hideTopicListIfLastReplyByBlocked`: 是否根据“最后回复人”命中黑名单隐藏主题行

## 已知说明

- 脚本以页面结构为基础做匹配，若站点改版可能需要更新选择器。
- 历史发帖标题来源于用户搜索页，受页面权限与结构影响。

## 常见问题

### Q1: 为什么删了脚本里的初始名单，页面仍然是拉黑状态？

因为实际生效的是本地存储中的黑名单数据。  
请在管理面板里移除，或通过“清空黑名单”处理，再导入你新的备份。

### Q2: 搜索框中文输入被打断怎么办？

当前版本已支持输入法合成态（IME）处理，中文可正常输入。  
若仍异常，请先禁用其他会重写输入框的脚本后重试。

### Q3: 与其他 Tampermonkey 脚本冲突怎么办？

建议先检查：

- 是否同时大范围监听 `MutationObserver`
- 是否存在全局样式类名冲突
- 是否在同一节点重复写 `display/style/class`

本项目已针对常见重排脚本做了观察范围与触发降噪优化。
